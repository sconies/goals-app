# Stage 6 (Goal map): what the core had to change

The stage page's entry criterion says "Goals' layouts and the roll-up of what feeds a goal are the core's (stage 3); the map draws them and adds nothing to them." The core rebuild (stages 1 to 3) had neither: Goals was the List only, with no Layout menu, and no group status (`worst`) anywhere. It also had no extension points, no `modulesOff`, no Features page and no MCP server (the Feedback module's session found the same). So most of the core changes below are things stages 1 to 3 should have built. Each is a finding.

**Core files changed: 4 (1 new).** Stages 1 to 3 still PASS (harness 100%, 14/14 contracts, on and off); the 18 scripted core journeys give the same verdicts as before, on and off.

Not changed, and why: the menu, Home, the import and the MCP server. The Goal map adds no menu row, Home card, records or AI tools (its section's table says "none" for each), so there was nothing to hide there. The core has no MCP server and no import screen at all, so "no MCP tool answers" and "the import says once what it didn't read" have nothing to act on for this module.
