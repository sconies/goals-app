# Stage 9 (Spreadsheets): gaps in the kit

The module is in `rebuild/modules/spreadsheets/`.

- **`xlsx.mjs`**: zip, .xlsx and CSV, using Node's zlib and no packages.
- **`export.mjs`**: the sheets, Start here, the template, JSON and the brief. They are made from `format.json`, which `gen-format.mjs` reads from `spec/core/export-format.md`.
- **`importer.mjs`**: header rows, which sheet a table is, what was read, worked-out edits, groups, leaving rows out and the rows to fix.
- **`undo.mjs`**: save, Past imports and Undo with kept rows.
- **`index.mjs`**: screens, routes and AI tools.
- **`worker.mjs`**: checks a large file off the server's thread.

The module has **no conformance rows of its own**. The only scored file it touches is `import.csv` (exit criterion 12), and the core's engine already scored 70 of 70 on it before this stage started. So **no behaviour in this stage was learned from a harness diff**. Every row below is GUESSED-RIGHT (the kit's words, a journey's words or my own round-trip test proved it), UNPROVEN or NOT-IN-KIT.
