Features

How Platform Engineering works, and the optional parts of Faro. They apply to everyone here.

How you work

  • Check-in rhythmEvery week, due by Thursday. A goal with no check-in for 14 days reads “No recent update”.Change
  • ReviewsWalk a set of goals together on a cadence, decide what happens next and keep what was said. 6 reviews are set up.On

Tools

  • Metric libraryDefine each number goals are measured by once, and say which metric measures a goal.On
  • SpreadsheetsDownload the goals as Excel or CSV, and load changes back from a spreadsheet.On
